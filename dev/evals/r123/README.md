# R1/R2/R3 的客观区分

| 层 | 本地能复现 | 本地不能冒充 |
|---|---|---|
| R1 | 15 个参考正例、12 个负例及评测器自检 | 45 个真实 Agent Trial 的成功率与增量 |
| R2 | 只读预检、证据覆盖、新命令边界单元测试 | 真实硬件、GUI、生产安全 |
| R3 | 规范一致性测试、回归和候选交付一致性 | 安装 vs 不安装的真实 Agent 效果 |

**隔离策略**：R1 原始试验包保持不变，不允许把本候选源码带入 v4.0.1 冻结试验。R3 若要定量比较须另建新试验（独立任务或正确处理重复测量），分层报告模型/宿主和改版条件。

本目录不包含秘密测试答案，真正的任务质量 oracle 位于单独的 R1-Evaluation-Kit；打包前要核对评分器没有进入 Agent 工作目录。
