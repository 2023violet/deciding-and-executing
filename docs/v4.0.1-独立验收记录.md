- 行为层：尚未在真实 Claude Code/Codex 实际运行原有 15 个触发/行为评测；**NOT VERIFIED**。
- Windows/macOS：**NOT VERIFIED**；Linux 当前环境验证不等于跨平台保证。
- 宿主真人审批：**NOT VERIFIED**，token 只能防止一步误操作，不能证明真人输入。

## 4. 明确的剩余限制与风险

1. **被 Git 忽略的数据**（本地配置、外部设备、环境变量等）不参与 Git 指纹；如果验证依赖它们，应使用独立输入快照/真实环境验证。单文件超过 32 MiB 的未跟踪文件将阻断，而不是跳过。
2. **范围外 Git 变化**：指纹依据当前本地 Git 状态，不构成对远端状态、外部服务或硬件状态的证明。
3. **静态审计非语义验证**：`sync` 只是证明审计器真实运行并通过其静态规则，不能证明报告文本真实、README 与源码语义一致。
4. **Shell 验证命令**：`verify_cmd` 由脚本执行；这是执行权，不是只读命令。计划确认和宿主权限仍不可省略。
5. **token 不是人类身份**：高风险操作应当在宿主层配置并实测权限规则；本包没有跨宿主强制真人审批的能力。
6. **待量化的整体收益**：仍需对照 Agent 不安装本 Skill 的成功率、误完成率、干预成本，不能仅凭单测数量宣称系统更优。
